# Online4Tech Repository

المستودع المركزي الرسمي لملفات **Online4Tech**، والمخصص لتجميع وتنظيم الملفات التي سيُعتمد عليها لاحقًا في بانل التحميل.

## الهدف

توفير مصدر موحد ومنظم للملفات القابلة للتنزيل، مع الاحتفاظ بمعلومات المصدر الأصلي والإصدار والتوافق وبصمة SHA-256 لكل ملف عند توفرها.

## قواعد أساسية

- هذا المستودع مستقل ويعمل بالتوازي مع جميع المستودعات والمصادر الحالية.
- لا يتم حذف أو نقل أو استبدال أي ملف من مصدره الأصلي؛ أي إضافة هنا تكون نسخة إضافية.
- لا يُعاد توزيع ملفات الطرف الثالث إلا بعد مراجعة الترخيص وشروط إعادة التوزيع.
- لا تُعتمد الحزم أو السكريبتات أو أوامر التثبيت قبل فحص المصدر والمحتوى والتوافق ومخاطر التشغيل.
- لا تُدرج بيانات غير مؤكدة على أنها موثقة أو مختبرة.
- لا يتم ربط هذا المستودع بالبانل أو تغيير مصادر التنزيل إلا بعد موافقة صريحة.

## الأقسام

| المسار | المحتوى |
|---|---|
| `plugins/` | البلجنات وبياناتها |
| `scripts/` | السكريبتات والأوامر |
| `packages/` | حزم IPK والملفات القابلة للتثبيت |
| `assets/` | الصور واللوجوهات وصور الاسكينات |
| `backups/` | النسخ الاحتياطية المؤرشفة |
| `releases/` | إصدارات مجمعة وملاحظات الإصدار |
| `catalog/` | فهارس JSON وبيانات العناصر |
| `checksums/` | بصمات SHA-256 |
| `docs/` | السياسات والتوثيق |

## حالة المستودع

حالة النسخ: **اكتمل نقل 911 من 911 أصلًا** إلى Releases المستودع المركزي، مع التحقق من الحجم وبصمة SHA-256 على دفعات النقل. لم يتم تعديل أو حذف أي Release أو ملف في المستودعات المصدرية. التحقق من البصمة لا يعني أن كل صورة أو حزمة اختُبرت عمليًا أو اعتُمدت للتثبيت.
