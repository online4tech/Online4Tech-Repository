# Release asset mirror queue

هذه الفهارس تحفظ روابط التنزيل الأصلية وبيانات المصدر والمطور، وتربطها بنسخ المستودع المركزي.

## الحالة الحالية
- **نقل الملفات الثنائية: مكتمل 911/911.**
- تمت مطابقة مفاتيح الفهرس مع Checkpoint النقل: 911 عنصرًا مكتملًا، دون عناصر ناقصة أو زائدة.
- فئات الفهرسة الحالية: 320 بلجن/حزمة، 200 سكين، 202 سكريبت/ملف نصي، 120 صورة/نسخة رسيفر، 23 Picons، 28 أداة Bridge، و18 ملفًا آخر.
- لم يتم تعديل أو حذف أي Release أو Asset في المستودعات المصدرية.
- تحقق SHA-256 يثبت سلامة النقل فقط؛ لا يعني أن الحزم أو الصور اختُبرت عمليًا أو أصبحت معتمدة للتثبيت.

## تنظيم النسخ الاحتياطية
- تم تصحيح التصنيف من 210 عنصرًا إلى **120 صورة/نسخة مرتبطة بموديلات رسيفرات**.
- تم فصل 89 عنصرًا لم تكن صور رسيفر: 9 بلجنز/حزم، 2 سكينات IPK، 77 سكريبتًا/ملفًا نصيًا، وملف APK واحد.
- تم وضع نسخة إعدادات القنوات في فئة الملفات الأخرى بدل خلطها بصور النظام.
- الفهرس البشري يرتب النسخ حسب الموديل، ويحافظ على أسماء الملفات وتواريخها وروابط التنزيل المركزية وروابط المصدر الأصلي.

## الخطوة التالية
مراجعة محتويات الأرشيفات والتوافق والتراخيص قبل اعتماد أي ملف للتثبيت أو ربطه بالبانل. لا يتم تنفيذ أي IPK أو سكريبت أو صورة تلقائيًا.
