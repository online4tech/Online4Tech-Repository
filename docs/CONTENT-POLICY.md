# Content Acceptance and Redistribution Policy

Before importing:
1. Record exact source URL, repository, author, retrieval date, and version/commit.
2. Review license and redistribution terms. If unclear or disallowed, do not upload the payload; metadata/reference only.
3. Inspect scripts and commands for destructive operations, credential handling, remote execution, and unexpected network access.
4. Record compatibility only when supported by evidence.
5. Test in a safe environment before marking as tested.
6. Generate SHA-256 for every binary/archive payload.

Statuses: pending_review, metadata_only, approved, tested, rejected.

Never delete or modify upstream sources, infer identity from filenames, silently overwrite versions, publish secrets/personal data, or claim safety/compatibility without evidence.
