# Contribution Rules

- Use UTF-8 and descriptive file names.
- Keep one version per directory.
- Update catalog metadata in the same change as payloads.
- Include SHA-256 for binary files.
- Record source and license; explain unknown values.
- Do not commit secrets, personal data, or unlicensed third-party files.
- Changes to any future download-panel feed require separate review and explicit owner approval.
